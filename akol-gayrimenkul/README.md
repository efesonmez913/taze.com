# Akol Emlak Gayrimenkul · web sitesi

Temmuz 2026'daki site. Tek değişiklik: portföy sayfası kaldırıldı.

- Menüdeki **Portföy** yerine **İlanlarımız ↗** var, sahibinden mağazasını açıyor: https://akolemlak06.sahibinden.com/
- Anasayfadaki ilan kartları kaldırıldı, yerine sahibinden mağazasına giden bir bölüm kondu.
- Hizmet listesindeki ve Bölge Rehberi'ndeki "portföye bak" linkleri mağazaya gidiyor.
- `portfoy.html` artık ziyaretçiyi doğrudan mağazaya yönlendiriyor.

Fotoğraflar (`assets/ofis-cephe.jpg`, `assets/ofis-vitrin.jpg`) senin bilgisayarındaki eski
klasörde duruyor. Bu klasörü eskisinin üzerine kopyalarsan aynen görünürler.

Çalıştırmak için: `npm run dev` (http://localhost:5190).

Tasarımı yenilenmiş deneme sürümü `../akol-gayrimenkul-v2/` klasöründe duruyor.
